
# Vancouver Cherry Blossom Festival: Blossoms After Dark

A high-fidelity web redesign project for Vancouver’s beloved spring event, Blossoms After Dark. This project captures the magical atmosphere of illuminated cherry blossoms at David Lam Park through an immersive, night-mode visual experience.

## Project Overview
As a visual designer based in Vancouver, I reimagined the festival's digital presence to better reflect its enchanting evening vibe. The goal was to balance elegant aesthetics with functional UX, ensuring visitors can easily find event schedules, vendor information, and transportation options.

### Key Design Features
* Immersive Dark Theme: A deep palette with pink glow accents to mimic the night-time illumination of cherry blossoms.

* Interactive Experience: Custom cursor interactions and scroll-reveal animations to enhance user engagement.

* Visual Storytelling: A magazine-style photo gallery and a dynamic falling petals effect using Canvas API.

### Technical Details
* Frontend: HTML5, CSS3 (Flexbox/Grid), JavaScript (ES6+)

* Canvas API: High-performance cherry blossom petal animation.

* Intersection Observer: Smooth scroll-reveal animations for content sections.

* Custom Cursor: Interactive cursor with easing effects for a premium feel.

* Responsive Design: Fully optimized for mobile, tablet, and desktop views.
